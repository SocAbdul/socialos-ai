# TikTok platform access

**STATUS: PLANNED**

- Intended official API: TikTok Content Posting API.
- Expected access: TikTok Login/OAuth and approved Content Posting scopes.
- Future API capabilities: direct video posting and photo posting where approved. SocialOS currently implements none of them.
- Review: Direct Post clients require audit to remove development visibility restrictions.
- Limits and media requirements must be discovered dynamically from the official creator information endpoint during implementation.
- Not implemented: developer application, OAuth, creator discovery, token storage, posting, status polling, analytics or webhooks.

Official references: https://developers.tiktok.com/products/content-posting-api and https://developers.tiktok.com/doc/content-sharing-guidelines/
