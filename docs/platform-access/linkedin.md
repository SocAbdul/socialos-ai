# LinkedIn platform access

**STATUS: PLANNED**

- Intended official API: LinkedIn Posts API.
- Expected access: OAuth 2.0 and approved products for member or organization publishing.
- Expected permissions: `w_member_social` and/or restricted `w_organization_social`, depending on account type.
- Future API capabilities: text, image, multi-image, video and document posts. SocialOS currently implements none of them.
- Review: organization publishing permissions and applicable Marketing API access may require LinkedIn approval.
- Limitations: versioned APIs, organization role requirements and media upload flows must be verified during implementation.
- Not implemented: application registration, OAuth, account discovery, token storage, publishing, analytics, comments and webhooks.

Official reference: https://learn.microsoft.com/linkedin/marketing/community-management/shares/posts-api
